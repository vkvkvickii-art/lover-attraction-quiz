# 《测测你最容易吸引什么样的恋人》趣味情感魅力测试网页

无需后端与第三方依赖，适配手机与电脑端响应式浏览，开箱即用。

## 目录结构

- `index.html`：模块化主页入口（双击即可运行，或直接上传至 GitHub Pages / Cloudflare Pages / Vercel）
- `css/style.css`：法式电影感 · 微醺浪漫杂志风样式表（丝绒暖杏白、暮色玫瑰粉、微醺紫罗兰、香槟金）
- `js/data.js`：15道精选大白话恋爱相处情境题库、六维魅力磁场定义与10类易吸引恋人完整档案
- `js/qrcode.js`：纯前端零依赖二维码矩阵生成模块（自动编码线上网址，离线可用）
- `js/app.js`：六维白化向量评分引擎、断点续答、SVG 魅力雷达图与原生 Canvas 高清海报绘制器
- `测测你最容易吸引什么样的恋人_单文件版.html`：合并了全部 HTML/CSS/JS 的独立单文件版，方便直接发微信/飞书双击打开

## 评分模型说明

从「温柔治愈力、清醒独立感、热烈生命力、智性神秘感、笃定安全感、浪漫共情力」六个维度出发，结合互补与共鸣机制匹配 10 类恋人画像（爹系/姐系引导型、阳光直球小狗型、智性恋高岭之花、温柔救赎守护型、浪漫文艺灵魂伴侣、欢喜冤家最佳损友、霸气护短行动派、反差萌傲娇猫系、人间烟火踏实居家、致命引力推拉高手）。经 10 万次蒙特卡洛模拟校准，每种类型自然触发概率均均衡稳定在 `9.6% ~ 10.1%` 之间。
